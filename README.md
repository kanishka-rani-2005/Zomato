# Zomato Clone

Live demo: https://zomato-phi.vercel.app/

## Project Overview

This repository contains a full-stack food delivery / reel sharing app with separate frontend and backend directories:

- `Frontend/` — React + Vite app
- `Backend/` — Node.js + Express API with JWT authentication and MongoDB models

## Features

- User registration and login
- Food partner registration and login
- Protected endpoints for likes, saves, and saved items
- Food partner profile and food video upload
- Saved reels with partner name display
- Dark mode and theme toggle
- Logout button and action menu


## Getting Started

### Frontend

```bash
cd Frontend
npm install
npm run dev
```

### Backend

```bash
cd Backend
npm install
npm start
```
