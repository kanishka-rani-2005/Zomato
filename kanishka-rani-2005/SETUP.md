# Publish this as your GitHub profile README

1. On GitHub, create a **public** repository named exactly `kanishka-rani-2005`.
2. Do not initialize it with a README, `.gitignore`, or license.
3. From this folder, run:

```powershell
git init
git add README.md .gitignore
git commit -m "Create GitHub profile README"
git branch -M main
git remote add origin https://github.com/kanishka-rani-2005/kanishka-rani-2005.git
git push -u origin main
```

GitHub recognizes a repository whose name matches your username and displays its `README.md` at the top of your profile.
